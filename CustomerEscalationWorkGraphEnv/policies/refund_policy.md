# Duplicate Payment Policy

When two successful payment transactions exist for the same customer, order, amount, and currency:

1. The earliest successful transaction is treated as the valid payment.
2. Any later duplicate successful transaction must be refunded.
3. The order payment status must be corrected to PAID if it is inconsistent with the valid successful payment.
4. The customer support case should be resolved only after the required remediation actions are recorded.
5. Failed or declined transactions must never be refunded.
